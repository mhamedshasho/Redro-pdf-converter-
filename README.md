# Redro PDF Converter

Android-first, offline-first PDF to Word converter.

## Project status
Planning baseline. No Android app or APK has been built yet.

## Initial technical direction
- Native Android application written in Kotlin.
- On-device PDF text extraction.
- DOCX generation using Open XML.
- Arabic and English interface with RTL support.
- No document upload or remote conversion service.
- OCR and advanced layout reconstruction are later milestones.

## Quality gate
The converter will not be called ready until unit tests, Android build checks, and real-device conversion tests pass. See the implementation plan, architecture, and test plan in docs/.

## Build status
Not built yet. A successful build will be reported only after CI actually completes.
